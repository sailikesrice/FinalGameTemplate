# Math Dungeon 🧮⚔️

A fun and educational math puzzle game where players navigate through dungeons solving equations to progress. Perfect for students learning basic arithmetic operations!

## 🎮 How to Play

### Getting Started
1. **Launch the Game**: Open the game in your web browser
2. **Choose Tutorial**: New players should start with the Tutorial to learn the basics
3. **Select Operations**: Choose which math operations you want to practice (addition, subtraction, multiplication, division)
4. **Start Playing**: Navigate through the dungeon and solve math puzzles!

### Game Modes

#### 🎓 Tutorial Mode
- **Perfect for beginners**: Learn the game mechanics step by step
- **Operation Selection**: Choose which math operations to practice (division is the default)
- **Interactive Learning**: Get familiar with controls and objectives
- **No Pressure**: Practice at your own pace

#### 👨‍🏫 Teacher Mode
- **Create Sessions**: Generate unique session codes for your class
- **Customize Settings**: Choose which operations students will practice
- **Monitor Progress**: Track student performance and completion times
- **Classroom Ready**: Perfect for educational environments

#### 👨‍🎓 Student Mode
- **Join Sessions**: Enter a session code provided by your teacher
- **Compete**: See how you rank against other students
- **Practice**: Work on the operations your teacher selected
- **Track Progress**: Monitor your improvement over time

## 🕹️ Controls

### Desktop Controls
- **W / ↑** - Move Up
- **S / ↓** - Move Down
- **A / ←** - Move Left
- **D / →** - Move Right
- **Space** - Interact with puzzles
- **ESC** - Pause game

### Mobile Controls
- **Touch Arrow Buttons** - Use the on-screen directional buttons
- **Drag Puzzle Tiles** - Touch and drag equation pieces to solve puzzles
- **Tap to Interact** - Tap on puzzles and doors to interact

## 🎯 Game Objectives

1. **Navigate the Dungeon**: Move through rooms using WASD or arrow keys
2. **Solve Math Puzzles**: Drag equation pieces to create correct equations
3. **Unlock Doors**: Correctly solved puzzles open doors to new areas
4. **Complete Levels**: Finish all rooms before time runs out
5. **Earn Points**: Each correct answer increases your score
6. **Beat the Clock**: Manage your time wisely - wrong answers cost time!

## 🧩 Puzzle Mechanics

### Equation Solving
- **Drag and Drop**: Move number and operation tiles to form correct equations
- **Visual Feedback**: Tiles snap into place and swap with others
- **Multiple Operations**: Practice addition (+), subtraction (-), multiplication (×), and division (÷)
- **Progressive Difficulty**: Equations get more challenging as you advance

### Mobile-Friendly
- **Touch Optimized**: All puzzles work perfectly on mobile devices
- **Responsive Design**: Game adapts to different screen sizes
- **Smooth Dragging**: Puzzle tiles respond naturally to touch gestures

## 🏆 Scoring System

- **Correct Answers**: Earn points for each equation solved correctly
- **Time Bonus**: Faster completion gives higher scores
- **Accuracy Matters**: Wrong answers reduce your score and waste time
- **Leaderboards**: Compete with other students in your session

## 🐛 Troubleshooting

### Common Issues
- **Tiles Not Dragging on Mobile**: Make sure you're using touch gestures (not mouse clicks)
- **Can't Join Session**: Double-check the session code and ensure you have internet connection
- **Game Not Loading**: Try refreshing the page or clearing your browser cache
- **Performance Issues**: Close other browser tabs to free up memory

### Getting Help
- Check that your browser is up to date
- Ensure you have a stable internet connection
- Try the tutorial mode if you're having trouble with controls
- Contact your teacher if you can't join a session
